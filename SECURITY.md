# Security

If you find a security problem in TrapRush, such as a way to access other players' accounts, get items or currency
you didn't earn, crash servers or cheat, **please don't open a public issue**. Public issues can be read by
everyone, including people who would abuse the problem before it is fixed.

Instead, open a private support ticket on the [TrapRush Discord](https://discord.gg/hw6Wqmw7A7) and include:

- What the problem is and what someone could do with it
- The steps to reproduce it
- Where it happens (browser, Steam on Windows or Mac, phone) and the game version if you know it

Please give us a reasonable amount of time to fix the problem before telling anyone else about it.
