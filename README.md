TrapRush is a free multiplayer party platformer for 2 to 12 players. Every round, everyone adds one item to the same
course. Some build a bridge, some hide a saw under it. Then everyone races to the flag at the same time. Make it to
the end while your friends don't, and you score.

This repository is the public home for **bug reports, feature requests and feedback**. The game's source code is not
here.

## Where to play

## What's in the game

- Online rooms for up to 12 players, public or private, with four-letter room codes and invite links
- 23 items, from planks and springs to lasers, black holes, teleporters and jetpacks
- Six maps: Forest, Factory, Snowfield, Desert, Harvest and Graveyard
- Unlockable skins and hats
- Optional accounts with levels, achievements, daily challenges, match history and a public leaderboard
- Keyboard and mouse on computers, touch controls on phones and tablets

New to the game? Read the [How to Play guide](https://traprush.io/how-to-play.html). Everything that has changed
since launch is on the [updates page](https://traprush.io/updates.html).

## Report a bug

1. [Search the existing issues](https://github.com/NAMERIO/TrapRush/issues?q=is%3Aissue) first. If someone already
   reported it, add a 👍 or a comment with your details instead of opening a new one.
2. Otherwise, [open a bug report](https://github.com/NAMERIO/TrapRush/issues/new?template=bug_report.yml).
3. Include where you play (browser, Steam on Windows or Mac, phone), what happened and how to make it happen again.
   A screenshot or short clip helps a lot.

Have an idea for a new item, map or feature?
[Suggest it here](https://github.com/NAMERIO/TrapRush/issues/new?template=feature_request.yml).

## Not for GitHub

Issues on GitHub are public. For anything about your own account, open a private support ticket on the
[TrapRush Discord](https://discord.gg/hw6Wqmw7A7) instead:

- Account help, ban appeals and reports about other players
- Purchases, diamonds and missing rewards
- Privacy and data requests

Found a security problem or a way to cheat? Please don't post it publicly. See [SECURITY.md](SECURITY.md).
